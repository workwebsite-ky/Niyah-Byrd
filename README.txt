HAIR BY NIYAHHLEYY — WEBSITE
============================

A 5-page, fully responsive website for Niyah Byrd's braiding studio.
Built with plain HTML, CSS and JavaScript — no build step, no dependencies.

HOW TO VIEW
-----------
Just double-click index.html to open it in any browser.
To put it online, upload the whole folder to any host (Netlify, Vercel,
GitHub Pages, Hostinger, etc.). index.html is the home page.

FILES
-----
index.html      Home
services.html   Services
pricing.html    Pricing (full price list)
about.html      About Niyah + FAQ
contact.html    Contact form + map
css/style.css   All styling (colors + fonts live at the top)
js/script.js    Menu, scroll effects, FAQ, form, back-to-top
images/         All photos + the portfolio video

EASY EDITS
----------
• Colors: open css/style.css — change the values under ":root" at the top.
  --hot is the neon pink; --ink is the near-black background.
• Fonts: swapped via the Google Fonts <link> in each page's <head>.
• Prices: edit the numbers in pricing.html (and the "from $..." on services.html).
• Facebook link: search every file for "facebook.com/niyah.byrd.2025" to update.
• Email: search for "NiyahByrd@gmail.com".
• Photos: replace files in /images with the same names to swap images,
  or update the <img src="..."> paths.

NOTES
-----
• Booking is handled by Facebook (buttons throughout link to the page).
• The contact form opens the visitor's email app addressed to Niyah
  (no server needed). For live form submissions you can later connect a
  service like Formspree.
• A short portfolio video (images/reel.mp4) is included in the folder for
  future use (e.g. social posts or a hero background).
